## Project Status

**This project is deprecated and no longer maintained.**

`rail-msg-sql` was an experimental Moov project that offered SQL access over raw payment rail messages (initially ACH files). It is unmaintained. **Do not use it for new work.**

This repository is archived for historical reference only.

<hr />

## What it was

An experiment to query raw payment-rail messages with SQL. The first (and only) rail was ACH. Additional rails were planned and never shipped.
